# Reference Site Analysis: aibootcamp-bat9qojt.manus.space

## Pages & Routes
1. `/` — Home/Landing page
2. `/module/:slug` — Individual module detail page
3. `/dashboard` — My Progress / Dashboard page

## Home Page Sections
- **Navbar**: Logo + nav links (Modules, Curriculum, FAQ, My Progress)
- **Hero**: Full-bleed neural network background image, badge label, large headline, subtitle, stats (rating, students enrolled, modules/hours)
- **Stats Bar**: 4 animated counters (Core Modules, Hours of Content, Hands-on Exercises, Project-Based %)
- **Curriculum Section**: "Six Modules. One Complete Journey." heading + subtitle + module cards grid (3 cols)
- **FAQ Section**: Accordion with 6 questions
- **CTA Footer Section**: "Your AI Career Starts Here" with feature checklist
- **Footer**: Logo, copyright, Privacy Policy, Terms of Service links

## Module Card Structure
- Module image (top)
- Number (01–06)
- Difficulty badge (Beginner/Intermediate/Advanced)
- Title
- Subtitle/tagline
- Description
- Duration + topics count
- "Explore" link

## Module Detail Page
- Back to all modules link
- MODULE XX label
- Title + subtitle
- Difficulty badge + hours + topics count
- About This Module paragraph
- Topics list (with type: video/reading/exercise/quiz, duration)
- "Add note" button per topic
- Start Module CTA button
- Prerequisites sidebar
- Tools & Technologies tags
- Next Module link

## Dashboard Page
- Header with overall stats (4 cards: Overall Progress %, Topics Completed X/54, Modules Completed X/6, Modules Remaining)
- Bootcamp Progress bar with module milestones (01–06)
- Module Roadmap list: each module shows number badge, title, subtitle, topic dots (1–9), progress %, Start button
- Reset All Progress button
- Back to all modules link

## Progress Tracking
- localStorage-based (no login required)
- Topics can be marked complete
- Progress persists across sessions
